# Jordan Gym Reviews

منصة رياضية للاكتشاف والتقييمات في الأردن: صفحة لكل نادٍ ومدرب ومنشأة ومتجر (الأسعار، الدوام، الصور، الموقع، واتساب).

> مشروع مستقل تماماً. لا يتشارك أي حساب أو مفتاح أو متغير بيئة أو قاعدة بيانات مع أي مشروع آخر.

## التقنيات

Next.js (App Router) · TypeScript strict · Tailwind CSS · Supabase (Postgres, Auth, Storage, RLS) · عربي RTL.

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # عبّي القيم، ولا ترفع الملف
npm run dev
```

## الفحص

```bash
npm run lint
npm run build
```

## سير العمل

- العمل على فروع جانبية (`feat/...`) مع معاينة Vercel.
- لا نشر على الإنتاج (`main`) إلا بطلب صريح من صاحب المشروع.

## الحالة

المرحلة الأولى (MVP) قيد البناء. الهيكل الأساسي فقط جاهز حالياً: لا قاعدة بيانات ولا ميزات بعد.
