# Jordan Gym Reviews

**دليلك للرياضة في الأردن** — منصة لاكتشاف ومقارنة النوادي والمدربين والملاعب وخدمات التغذية والمتاجر الرياضية، مع صفحات للأنشطة وتقييمات وتواصل مباشر وأدوات مجانية لأصحاب الأنشطة.

## الهوية البصرية
دليل الهوية المعتمد موجود في [docs/brand-identity.md](docs/brand-identity.md). النظام البصري مبني على الكحلي العميق، الأخضر الزمردي، ولمسات الليموني، مع Cairo للعربية وواجهة RTL-first.

## التقنيات
Next.js (App Router) · TypeScript strict · Tailwind CSS · Supabase (Postgres, Auth, Storage, RLS) · عربي RTL.

## التشغيل محلياً
```bash
npm install
cp .env.example .env.local   # عبّئ القيم محلياً ولا ترفع الأسرار
npm run dev
```

## الفحص
```bash
npm run lint
npm run build
```

## سير العمل والنشر
- التطوير على فروع `feat/*` مع معاينات Vercel.
- لا يُنشر على الإنتاج (`main`) دون موافقة صريحة.
- تغييرات قاعدة البيانات تُطبّق عبر مسار migrations المعتاد، ثم تُتحقق قبل دمج أي ميزة تعتمد عليها.
- لا تضع مفاتيح أو بيانات شخصية في المستودع أو ملفات الهوية العامة.

## ملاحظات التشغيل
- ملصق QR متاح للأنشطة المنشورة ولأعضاء النشاط أو مديري المنصة.
- إحصاءات زيارات QR تعتمد على تطبيق migration الخاص بنوع الحدث `qr_visit` على قاعدة Supabase المرتبطة قبل تفعيلها بالكامل.
